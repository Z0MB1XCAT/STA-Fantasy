# STA Fantasy

Fantasy racing for the STA league, modelled on F1 Fantasy. Static site on GitHub Pages, with a small free Supabase
project that stores players' teams and enforces the pick deadline.

## Every race weekend (about 5 minutes)

**Friday, after the races**
1. Open `admin.html` on the live site (or locally). Choose the round.
2. For each of Short Quali, Reverse Grid and Feature Race: paste the finishing order from SimGrid (one driver per line,
   P1 first, usernames work) or tap drivers in order. Mark DNF / DSQ / DNS, pick the fastest lap.
3. Check the **Points preview**, press **Copy file**.
4. On GitHub open `data/rounds/NN.txt` (NN = round number), click the pencil, select all, paste, **Commit changes**.
   Leave `status: provisional`. The site updates in a minute or two and shows a yellow *Provisional* badge.

**Sunday, after the stewards**
1. Reopen the round in `admin.html`. It loads the existing file. Fix any penalties (move drivers, add `:dsq`, etc.).
2. Set the status to **Final**, copy, and paste it over `data/rounds/NN.txt` again.
3. That's it. Prices update, transfers open for the next round, and the league table stops saying provisional.

**Before the deadline, if you know a driver is missing:** open `admin.html`, choose **Driver changes**, add the absent
driver and the reserve, leave status **Upcoming**, and commit. Owners can then swap that driver for free and the
reserve appears in the market.

You can also edit the `.txt` files by hand. The format is documented at the top of every file in `data/rounds/`.

## The rules in one screen

- 5 drivers + 2 constructors, $100M budget, one DRS Boost driver (2x). First team is free; then 2 free transfers a round
  (1 banks), -10 points per extra transfer.
- Chips (once each): Wildcard, Limitless, Extra DRS, No Negative, Autopilot.
- Deadline = start of Short Quali, Friday 8 pm UK time. Everyone's picks become visible then.
- Points are provisional until you set the round to Final. Prices and the next transfer window only open on Final.
- Absent driver after the deadline: owners score the reserve's points. Announced before: free swap.
- Full scoring tables and all numbers live in `data/season.json` (the Rules page renders from that file).

## Where things live

| What | Where |
|---|---|
| Race results (the only file you edit weekly) | `data/rounds/01.txt` ... `12.txt` |
| Calendar and deadlines | `data/calendar.json` (also the `rounds` table in Supabase) |
| Drivers, teams, colours | `data/roster.json`, `data/teams.json` |
| Prices before round 1 | `data/drivers.json` (generated by `node tools/seed-prices.mjs`) |
| Scoring, budget, chips, price rules | `data/season.json` |
| Past seasons | `data/history/seasons.json` (parsed from the SimGrid tables) |
| Players, picks | Supabase (project `STAFantasy`, London) |

## Setting rookie prices properly

Eleven drivers have no history, so they are priced from their SimGrid rating. Put the 4-digit rating next to each name in
`data/history/ratings.json`, then run:

```bash
node tools/seed-prices.mjs
```

Do this **before** the first deadline: it rewrites `data/drivers.json`, and prices should not change once people have picked.
The tool prints every price so you can sanity-check it.

## Images and branding

- **Team art** lives in `images/teams/`. `data/teams.json` points each team at its `logo`, `car`, and a `photos` map that
  gives every league driver one of the team's real-driver figures. Swap two codes there to change who gets which picture.
  Reserves have no photo and show a silhouette.
- **League logo:** save it as `images/league-logo.png` (a square image of the round logo). It appears in the header
  automatically. Then run `node tools/dev/make-icons.mjs` to turn it into the phone home-screen icons.
- **Track outlines:** `images/tracks/*.svg` (white outlines from formula1.com), linked per round by `track` in
  `data/calendar.json`. The source pattern is
  `https://media.formula1.com/image/upload/c_lfill,w_3392/v1740000001/common/f1/2026/track/2026track<name>whiteoutline.svg`.
- **Nationalities:** `nat` in `data/roster.json` (flag codes such as `gb`, `us`, `gb-wls`). Fill in the blanks as you
  learn them, then run `node tools/seed-prices.mjs` (prices do not change, it only copies the field across).
- **Discord:** the invite link is `discord` in `data/season.json`; it shows in the footer, on Home, on Rules and in the
  sign-up box.
- **Page shells:** the six `.html` files are generated from one template. Edit `tools/dev/build-pages.mjs` and run it,
  rather than editing the HTML files by hand.
- Players can "install" the site from their phone browser (Add to Home Screen); it opens full screen like an app.

## Changing a lineup

Edit `data/roster.json` (team, role), regenerate prices if needed, and push. For a permanent replacement mid-season, give
the new driver `role: regular`, and set `"retired": true` on the departed driver in `data/drivers.json`. Owners of a
retired driver get a free swap.

## Running it locally

```bash
node serve.mjs                       # http://localhost:3000
node --test tests/*.test.mjs         # engine tests
node tools/make-demo.mjs             # fake rounds for trying the UI, written to tests/fixtures
```

Demo mode (no login, fake players, never touches Supabase):
`http://localhost:3000/index.html?rounds=tests/fixtures/rounds&store=local&demo=1&now=2026-11-04T12:00:00Z`

`?now=<ISO time>` pretends it is that moment on any page, handy for checking deadline states.

## Dev tools

- `node tools/dev/audit.mjs`: checks every page against the real backend for console errors, failed requests,
  missing alt text, unlabeled buttons and sideways scrolling on phones. Run it before you publish changes.
- `node tools/dev/build-pages.mjs`: regenerates the HTML shells, `404.html` and the manifest from one template.
  Run it with `SITE_URL=https://<you>.github.io/<repo>` once the site is live so Discord shows the preview image.
- `node tools/dev/make-og.mjs`: redraws the link-preview image (`images/app/og.png`).
- `node tools/dev/make-icons.mjs`: redraws the home-screen icons from the league logo.
- Developer URL switches (`?store=local`, `?demo=1`, `?now=`, `?rounds=`) only work on localhost.

## Admin notes

- Sign-up is open to anyone with the link (the `join` edge function allows at most 15 new accounts per 10 minutes, so a
  script can't flood the league). To remove a player: Supabase dashboard, Authentication, Users, delete them.
- Players log in with name + password (no email). If someone forgets their password they message the contact in
  `data/season.json` (`contact`, currently Z0MB1XCAT), who resets it in the Supabase dashboard (Authentication, Users).
- If a race date moves, change it in `data/calendar.json` **and** in the Supabase `rounds` table (`lock_at`). The database
  is what actually enforces the deadline.
- The publishable key in `js/config.js` is meant to be public. Never commit the service-role key.
